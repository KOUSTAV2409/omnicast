Omnicast is public — Manhattan without AI first

omnicast.best is live. The repo is public. Anyone on Omarchy can clone and run — no invite gate.

Omnicast is an umbrella launcher for Omarchy: Alt+Space searches your machine, hands off to native tools when they already win, and owns the gaps (calc, scripts, snippets, windows helpers, ranking).

Not affiliated with omarchy.org. Independent community project. It intends to earn a place in that ecosystem.

How we take Manhattan

First we take Manhattan, then we take Berlin — but Manhattan here means the non-AI daily loop. Finish every handoff, own, and curate surface that does not need a model. Ask AI can stay mocked until that loop is trustworthy.

Real streaming AI (Ollama / BYOK) comes later. A separate research mission — an ultra-light Omarchy-specialist local model — stays out of band from Omnicast milestones. We will not couple the umbrella to that work.

Install

git clone https://github.com/KOUSTAV2409/omnicast.git
cd omnicast
./bin/omnicast

Bind Alt+Space to the absolute path of bin/omnicast. Keep Super+Space for the Omarchy menu. Details on the home page.

What’s next

  • Dogfood the non-AI loop end to end
  • Close remaining handoff / own / curate gaps
  • Declare Manhattan taken — then Berlin (packaging, plugins, deeper Hyprland)
