Manhattan taken (non-AI)

First we take Manhattan, then we take Berlin.

Today Omnicast declares Manhattan taken: the non-AI Alt+Space daily loop on Omarchy is trustworthy enough to call complete. Ask AI remains a mock. That was always the deal (ADR 015).

What “taken” means

From one hotkey you can:

  • Launch apps and Omarchy CLI commands with fuzzy search, frecency, favorites, and aliases
  • Hand off to native Omarchy surfaces: clipboard, emoji, theme, background, images, keybindings, menu, capture, share, reminders, Find Files
  • Own the gaps: calculator, quicklinks, script commands, in-launcher snippets, typed file search with side preview, curated Windows helpers
  • Fall back to Search Web when nothing matches (Ask AI stub is honest about being a stub)

Catalog honesty landed with this declaration: while commands or files are still indexing, Omnicast shows a loading row instead of fake Web or AI fallbacks.

What we did not ship

  • Real AI streaming (Ollama / BYOK): Berlin+, optional
  • A global keystroke snippet expander: removed; snippets live in the launcher
  • A Raycast UI clone: Omnicast stays an Omarchy umbrella

Berlin starts now

Default packaging is the Omarchy plugin plus an OPR package for pkgs.omarchy.org (PR open on omacom/omarchy-pkgs#1573). AUR is demoted—only if we target vanilla Arch later. Deeplinks and Hyprland float snaps already shipped; next is publishing OPR, then plugin-store handoff in the umbrella, and an extension story that stays scripts-first.

Install stays the same:

omarchy plugin add https://github.com/KOUSTAV2409/omnicast.git --enable

Not affiliated with omarchy.org. Independent community project that intends to earn its place.

First we take Manhattan, then we take Berlin.
