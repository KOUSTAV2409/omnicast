Building a true Raycast alternative for Omarchy Linux

If you have ever used Raycast on macOS, you know the feeling: once it enters your muscle memory, every other desktop environment feels incomplete. On Linux, people have tried to bridge this gap with application launchers and dmenu scripts, but they often lack the fluid, unified experience: split previews, rich metadata, modal actions, and instant responsiveness.

With Omnicast, our mission began with a clear principle: first make it an uncompromising daily driver for Omarchy, then expand it across the Linux world.

The one-line install

No more manual git cloning or hunting down configuration files. You can now set up Omnicast on Omarchy with a single command:

curl -fsSL https://omnicast.best/install | bash

The installer validates prerequisites, installs Omnicast to ~/.local/share/omnicast, puts the binary on your PATH, registers the desktop entry, and binds Alt+Space in your Hyprland configuration while preserving Super+Space for the native Omarchy menu.

Live split file preview

Searching for files now feels like a document browser, not a raw list dump. When you search for files (like quicknotes.md), Omnicast opens a split view:

  • Formatted Markdown: Rendered headings, lists, and prose directly inside the card.
  • Code syntax highlighting: Accurate syntax blocks for Python, JavaScript, Rust, Bash, and config files.
  • Smart editor handoff: Files open with your preferred editor through omarchy-launch-editor. If your editor is terminal-based, like Neovim, Omnicast automatically wraps it in Ghostty so your editor appears immediately.
  • Security hardening: Built-in path safety guards automatically filter out private keys, session tokens, and sensitive directories.

Native Omarchy clipboard integration

Instead of running duplicate clipboard daemons that compete for memory, Omnicast connects directly to Omarchy's native state files. Any screenshot taken with Flameshot, copied image, code snippet, or color code is instantly indexed.

Color codes show visual swatches alongside HEX, RGB, and HSL values. Code snippets detect their language automatically. Pinned items stay permanently on top with Ctrl+P, and pressing Enter pastes directly into your active window.

100+ native system commands

Omnicast indexes the entire Omarchy CLI catalog directly into your root search. Screenshots, audio input muting, nightlight toggling, theme switching, font previews, and AI agent prompts are all accessible with a single keystroke.

First Manhattan, then Berlin

By focusing deeply on Omarchy first, we built a tool that is fast, resilient, and native. The daily non-AI loop is now fully operational: app launching, file search with live preview, clipboard history, calculator, snippets, and window management.

From here, our next step is packaging for the Arch User Repository (AUR) and modularizing system hooks so Omnicast can bring this experience to Fedora, Ubuntu, and generic Wayland setups.

First we take Manhattan, then we take Berlin.
