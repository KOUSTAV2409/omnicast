Omnicast is now listed on Omarchy Plugins

Today marks an exciting milestone for the Omnicast project: Omnicast is officially approved, verified, and published on the Omarchy Plugin Marketplace!

You can find our official listing on the directory at omarchyplugins.com/plugin.html?id=koustav.omnicast.

What is Omnicast?

Omnicast brings the fluid, keyboard-driven productivity workflow of Raycast to Omarchy Linux and Hyprland. Bound to Alt+Space, it serves as an umbrella launcher designed to keep you in flow:

  • Universal Search: Search installed desktop applications, user files, quicklinks, and Omarchy CLI commands from a single keystroke.
  • Live Split Previews: View rendered Markdown, syntax-highlighted code, image thumbnails, and PDF extracts side-by-side with your search results before opening any application.
  • Deep Omarchy Integration: Control themes, wallpapers, window layouts, audio, and system actions natively.
  • Script Commands & Calculator: Run community script commands with custom arguments and compute complex math formulas inline.

End-to-end security hardening

Submitting to the Omarchy Plugin Marketplace involves a thorough review process. To ensure user safety, we put Omnicast through an extensive security overhaul prior to approval:

  • Zero Process Argument Leakage: Sensitive data, such as clipboard contents, snippet bodies, search queries, and quicklink parameters, is never passed via command-line arguments (sys.argv). All sensitive payloads are piped strictly through standard input (stdin), preventing exposure in /proc/<pid>/cmdline or ps aux.
  • Remote Asset Protection: All file preview and metadata cards enforce strict plain-text rendering and sanitize HTML tags. This prevents Qt's auto-rendering engine from triggering remote network requests for embedded images, protecting your IP address and network footprint.
  • Filesystem Boundary Defense: Path traversal protections keep file searches confined strictly to $HOME and designated scopes. Sensitive credentials, such as SSH keys, GPG rings, cloud tokens, browser profile databases (cookies, saved logins), and .env files, are blocked from indexing.
  • Zero Elevated Privileges: Omnicast runs entirely unprivileged within user space without requiring sudo or background privileged daemons.

The marketplace team verified these protections, granting Omnicast full maintainer verification.

Get started with Omnicast

You can install Omnicast directly from the marketplace listing, or clone and install from source:

curl -fsSL https://omnicast.best/install | bash

Once installed, press Alt+Space to launch.
