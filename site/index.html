Omnicast

Alt+Space for Omarchy.

One launcher that hands off to native Omarchy tools — and owns the gaps Raycast users miss on Linux.

Clone and run GitHub

Install on Omarchy

Needs Omarchy (Hyprland) and Quickshell. Not macOS. Not a generic Arch box without Omarchy.

git clone https://github.com/KOUSTAV2409/omnicast.git
cd omnicast
./bin/omnicast

# Bind Alt+Space to the absolute path of bin/omnicast
# Keep Super+Space for the Omarchy menu
