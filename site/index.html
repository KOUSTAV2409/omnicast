omnicast

community project for Omarchy

Alt+Space for Omarchy.

Free and open source. Assembles Omarchy’s tools under one launcher — handoff what’s already great, fill the gaps, keep the UX tight. Built for the community, not a product pitch.

Omnicast is not affiliated with omarchy.org today. It is an independent community project that intends to earn a place in that ecosystem.

Clone & run The code Omarchy

Install on Omarchy

Needs Omarchy (Hyprland) and Quickshell on PATH. Not macOS.

foot · ~/omnicast 
# clone the public repo
$ git clone https://github.com/KOUSTAV2409/omnicast.git
$ cd omnicast
$ ./bin/omnicast

Then bind Alt+Space to the absolute path of bin/omnicast in ~/.config/hypr/bindings.lua. Keep Super+Space for the Omarchy menu.
