Alt+Space for Omarchy.

Hands off to native tools. Owns the gaps Raycast users miss on Linux.

Clone and run

Install on Omarchy

Needs Omarchy (Hyprland) and Quickshell. Not macOS.

git clone https://github.com/KOUSTAV2409/omnicast.git
cd omnicast
./bin/omnicast

# Bind Alt+Space → absolute path of bin/omnicast
# Keep Super+Space for the Omarchy menu
